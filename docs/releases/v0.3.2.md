# Agent Home v0.3.2 — first public macOS preview

**Talk to your Codex agent, anywhere.**

Agent Home is a free, local app that connects Telegram to your existing Codex
root sessions. Continue a project from your phone with text, images, videos,
and voice notes while your computer does the work.

## Download and install

- **Apple Silicon Mac, macOS 15 or later:** download
  `Agent-Home-0.3.2-macOS-arm64.dmg`, drag Agent Home into Applications, then open it.
- The dashboard opens inside the app. Python and Node are not required for the DMG.
- Install and sign in to Codex CLI separately. Use the in-app **Get started** guide
  to create an identity, assign a sleeve, connect a Telegram bot, and allow your
  Telegram account in **External Identities**.
- Compare the download with `SHA256SUMS` using `shasum -a 256 <downloaded-file>`.

## Included

- Durable agent identities with assignable Codex root-session sleeves.
- Independent Telegram bot connections and explicit sender access policies.
- Incoming text, photos, videos, and voice notes; outgoing image/video attachments.
- Admin menus for creating identities, assigning sleeves, and connecting bots.
- Local SQLite storage, storage settings, and explicit recovery of managed sleeves.

## Preview limits

The app is ad-hoc signed and **not Apple notarized**. If macOS blocks it, review
this release and its source, then follow [Apple's Open Anyway instructions](https://support.apple.com/en-us/102445).
Intel Macs can build from source; the downloadable DMG is Apple Silicon only.
The Python server also supports Linux; Windows is not supported yet.

Your computer must remain awake, online, and running Agent Home. Voice and video
decoding depend on the tools available to your Codex agent. Incoming files are
limited to 20 MB. Codex/model-provider charges, if any, are separate from this
free tool. There is no automatic updater or automatic login startup.
