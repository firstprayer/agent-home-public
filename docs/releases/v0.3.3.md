# Agent Home v0.3.3 — Apple Silicon and Intel macOS previews

**Talk to your Codex agent, anywhere.**

## Choose your download

Both installers require macOS 15 or later. In **Apple menu → About This Mac**, a
**Chip** entry naming an Apple M-series chip means Apple Silicon; an Intel
**Processor** entry means an Intel Mac.

| Mac | Installer |
|---|---|
| Apple Silicon | `Agent-Home-0.3.3-macOS-arm64.dmg` |
| Intel | `Agent-Home-0.3.3-macOS-x86_64.dmg` |

Drag Agent Home into Applications and open it. Install and sign in to Codex CLI
separately, then follow the in-app **Get started** guide. Upgrading preserves
settings, agent identities, Telegram connections, and sleeve assignments in the
existing local database.

## Changes

- GitHub Actions builds both macOS architectures on native runners.
- Both frozen packages must pass startup, restart, storage and process-lifecycle
  checks, and their executable architectures are verified before publication.
- Both DMGs and their SHA-256 checksums are published in the same Release.

Use `shasum -a 256 <downloaded-file>` to compare your installer with `SHA256SUMS`.
The packages remain ad-hoc signed and **not Apple notarized**. If macOS blocks
one, review the release and follow [Apple’s Open Anyway instructions](https://support.apple.com/en-us/102445).

The Python server also supports Linux. Windows is not supported yet. This free
tool requires your computer to remain awake, online, and running Agent Home;
model-provider charges remain separate. Agent Home uses AGPL-3.0-only, with
third-party components retaining their own licenses.
